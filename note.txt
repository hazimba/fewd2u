## fewd2u

Technical Requirements

1. Frontend: React or Next.js for SSR.
2. Backend: Node.js
3. Database: Firestore (firebase)
4. Authentication: Firebase
5. Hosting: Vercel (frontend && backend)
6. QR Code Generation: Backend generates a QR code linked to the restaurant’s menu URL.

Firebase (Google’s Native Choice)
✅ Tight integration with Google Cloud.
✅ Authentication (email/password, Google login, etc.).
✅ Firestore or Realtime Database (scales automatically).
✅ File storage for food images (Firebase Storage).
✅ Firebase handles JWT internally → you don’t have to implement password hashing, session storage, etc
✅ SDK for web, so you can call directly from Next.js (no custom API needed unless you want business logic).
Best if → You want quick setup, easy auth, and you’re happy with Firebase’s ecosystem.
